Для работы бота необходимо создать переместить файл js_tg_bot_token.txt в директорию на одном уровне с папкой бота.
В этот файл необходимо внести ключ бота, полученный от Botfather в телеграмме.

После создания файла с ключом, необходимо открыть терминал и ввести npm start.

В будущих версиях будет добавлен отдельный файл для запуска бота.
